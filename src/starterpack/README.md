# StarterPack

This folder is for starter items that players receive when they join.

**Note:** StarterPack typically contains Tools, not scripts. Scripts go in other locations.

To add a tool:
1. Create a Tool instance in Roblox Studio
2. Export it or reference it here
3. Tools will be given to players when they spawn

Example structure:
- `src/starterpack/Items/Sword` (Tool instance)
- `src/starterpack/Items/Shield` (Tool instance)
